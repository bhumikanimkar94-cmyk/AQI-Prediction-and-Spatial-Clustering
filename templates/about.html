About Project

Air Quality Index Analysis & Spatial Pollution Clustering

🌿 Project Overview

This project analyzes air pollution data to understand AQI levels and pollution patterns across different locations in India.

A Random Forest model is used to predict AQI from pollutant values, while K-Means clustering is used to identify different pollution groups.

Technologies Used:

Python • Pandas • Scikit-learn • Flask • HTML • CSS • JavaScript • Chart.js • Leaflet
