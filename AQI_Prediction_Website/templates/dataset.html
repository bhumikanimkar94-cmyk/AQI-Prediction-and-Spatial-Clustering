Data Cleaning

Before applying machine learning and clustering, the dataset was cleaned to improve the quality of the analysis.

  • AQI Cleaning: Missing or invalid AQI values were converted and removed.
  • AQI Outliers: AQI values above 500 were removed from the analysis.
  • Missing Pollutant Values: Missing pollutant values were replaced using the median value of the respective pollutant.
  • India Filtering: Geographical coordinates were used to identify Indian locations for spatial clustering.

📌 Dataset Role in the Project

The cleaned dataset is used as the foundation of the complete project. Pollutant values are used by the Random Forest model for AQI prediction, while Latitude, Longitude and AQI are used for K-Means pollution clustering.
