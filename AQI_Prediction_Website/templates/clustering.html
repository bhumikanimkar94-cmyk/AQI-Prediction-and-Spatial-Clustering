How Clustering Works

The project uses the K-Means clustering algorithm to divide the analyzed Indian locations into three groups. The clustering considers Latitude, Longitude and AQI so that locations are grouped using both geographical position and pollution level.

1. Input Features

Latitude, Longitude and AQI values are used as the clustering features.

2. Standardization

The selected features are standardized using StandardScaler before applying K-Means.

3. K-Means

K-Means divides the locations into three clusters based on similarity.

🔎 Key Finding

The clustering analysis identified three pollution groups among the 134 Indian locations. The High Pollution cluster has the highest average AQI of 138.56, while the Low Pollution cluster has an average AQI of 87.54.
